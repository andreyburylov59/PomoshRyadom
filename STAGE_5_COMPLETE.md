## 📊 Технические детали

### Формула расстояния (Haversine)
```javascript
calculateDistance(lat1, lon1, lat2, lon2) {
    const R = 6371; // Радиус Земли в километрах
    const dLat = this.toRad(lat2 - lat1);
    const dLon = this.toRad(lon2 - lon1);
    
    const a = Math.sin(dLat / 2) * Math.sin(dLat / 2) +
              Math.cos(this.toRad(lat1)) * Math.cos(this.toRad(lat2)) *
              Math.sin(dLon / 2) * Math.sin(dLon / 2);
    
    const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));
    const distance = R * c;
    
    return distance;
}
```

## ⚠️ Примечания

1. **Координаты центров районов** — упрощённые, для демонстрации. В продакшене нужна настоящая база координат границ районов.

2. **Точность геолокации** зависит от устройства и настроек. На десктопе точность ~100-500м, на мобильных с GPS ~5-20м.

3. **HTTPS требуется** для Geolocation API в продакшене (кроме localhost).

4. **Браузерная поддержка** — все современные браузеры, кроме IE.

5. **Кэширование координат** — Geolocation API кэширует результат на 5 минут (параметр `maximumAge: 300000`).
