# Контекст для агента — Помощь Рядом

## Продукт

Веб-приложение, которое соединяет заказчика и исполнителя **в одном районе**.

Сценарий: пожилой человек голосом создаёт задание («уберите квартиру»), сосед видит его в радиусе нескольких километров, платит 50 ₽ за контакт, звонит по `tel:`. Чатов нет специально.

Это не клон Профи.ру/Юду: гиперлокальность, голос, крупные кнопки, маскированный телефон до оплаты.

## Известные ограничения MVP

- Район по геолокации — ближайший из 10 демо-центров (координаты около Москвы), не реальные границы.
- Фильтр «рядом» только в браузере; задания без координат остаются видимыми.
- Редактирование задания не обновляет координаты.
- Оплата контакта — симуляция, не боевой СБП.
- CSRF не включён.
- `PROJECT_STATUS.md` раньше утверждал 2/10 — это устарело.
