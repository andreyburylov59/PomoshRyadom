## ❓ ЧАСТЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема 1: "python не является внутренней командой"

**Решение:**
1. Переустановите Python
2. При установке **ОБЯЗАТЕЛЬНО** поставьте галочку "Add Python to PATH"
3. Или добавьте Python в PATH вручную:
   - Найдите где установлен Python (обычно `C:\Users\ВашеИмя\AppData\Local\Programs\Python\Python311\`)
   - Добавьте этот путь в переменные среды PATH

### Проблема 2: "pip не является внутренней командой"

**Решение:**
```cmd
python -m pip install --upgrade pip
```

### Проблема 3: Ошибка при установке Pillow

**Решение:**
```cmd
pip install --upgrade pip
pip install Pillow
```

### Проблема 4: Порт 5000 занят

**Решение 1:** Найдите и закройте процесс, использующий порт 5000

```cmd
netstat -ano | findstr :5000
taskkill /PID <номер_процесса> /F
```

**Решение 2:** Измените порт в `app.py` (последняя строка):

```python
app.run(host='0.0.0.0', port=5001, debug=True)
```

Теперь открывайте `http://127.0.0.1:5001`

### Проблема 5: База данных не создается

**Решение:**
```cmd
python recreate_db.py
python app.py
```
