  🚀 БЫСТРЫЙ СТАРТ: Помощь Рядом на Windows

📍 АДРЕС УСТАНОВКИ: E:\Cursor\PomoshRyadom\

═══════════════════════════════════════════════════════════════════
  ШАГ 1: СКАЧАТЬ ПРОЕКТ
═══════════════════════════════════════════════════════════════════

ВАРИАНТ A: Через Git (если установлен)
---------------------------------------
1. Откройте командную строку (Win + R → cmd → Enter)

2. Выполните команды:

E:
mkdir Cursor
cd Cursor
git clone https://github.com/andreyburylov59/PomoshRyadom.git PomoshRyadom
cd PomoshRyadom


ВАРИАНТ B: Скачать ZIP (проще)
--------------------------------
1. Откройте: https://github.com/andreyburylov59/PomoshRyadom

2. Нажмите зеленую кнопку "Code" → "Download ZIP"

3. Распакуйте архив в E:\Cursor\

4. Если нужно, переименуйте папку в "PomoshRyadom"


═══════════════════════════════════════════════════════════════════
  ШАГ 2: УСТАНОВИТЬ PYTHON (если еще не установлен)
═══════════════════════════════════════════════════════════════════

1. Скачайте: https://www.python.org/downloads/

2. Запустите установщик

3. ✅ ОБЯЗАТЕЛЬНО поставьте галочку "Add Python to PATH"

4. Нажмите "Install Now"

5. Проверьте установку:

python --version

Должна быть версия 3.10 или выше


═══════════════════════════════════════════════════════════════════
  ШАГ 3: УСТАНОВИТЬ ПРОЕКТ
═══════════════════════════════════════════════════════════════════

1. Откройте папку: E:\Cursor\PomoshRyadom\pomosh_ryadom\

2. Найдите файл: install.bat

3. Дважды кликните на install.bat

4. Дождитесь завершения установки

✅ Готово! Всё установлено автоматически!


═══════════════════════════════════════════════════════════════════
  ШАГ 4: ЗАПУСТИТЬ ПРИЛОЖЕНИЕ
═══════════════════════════════════════════════════════════════════

1. В папке E:\Cursor\PomoshRyadom\pomosh_ryadom\

2. Найдите файл: start.bat

3. Дважды кликните на start.bat

4. Откроется окно с текстом:
   "📍 Откройте в браузере: http://127.0.0.1:5000"

5. Откройте браузер и перейдите на:
   http://127.0.0.1:5000

✅ Приложение запущено!


═══════════════════════════════════════════════════════════════════
  ШАГ 5: ПОСМОТРЕТЬ ПРЕЗЕНТАЦИЮ (опционально)
═══════════════════════════════════════════════════════════════════

1. В папке E:\Cursor\PomoshRyadom\pomosh_ryadom\

2. Найдите файл: presentation.bat

3. Дважды кликните на presentation.bat

✅ Презентация откроется в браузере!

Проблема: "python не является внутренней командой"
---------------------------------------------------
Решение: Переустановите Python с галочкой "Add Python to PATH"


Проблема: Порт 5000 занят
--------------------------
Решение: Откройте app.py и измените 5000 на 5001 в последней строке


Проблема: База данных не создается
-----------------------------------
Решение: Запустите reset_db.bat
