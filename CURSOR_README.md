## 🎯 ЦЕЛИ ПРОЕКТА (НАПОМИНАНИЕ)

### Для кого:
- 👵 **Пожилые люди** (заказчики) - нужна помощь, но Профи/Юду слишком сложны
- 💼 **Молодежь** (исполнители) - подработка рядом с домом

### Уникальность:
- 🎙️ **Голосовой ввод** - говоришь → форма заполняется
- 📍 **Гиперлокальность** - только соседи (1-3 км)
- 📞 **Без чатов** - только прямые звонки
- 💰 **Дешевле** - 50₽ vs 80-150₽ у конкурентов

### Размер рынка:
- **30+ млн** пожилых людей в России
- Только **4%** пользуются P2P платформами
- **28+ млн потенциальных пользователей** не пользуются из-за сложности

**A:** Скажите Cursor AI:

### Q: Как изменить дизайн?

**A:** Все стили в `static/css/style.css`. CSS переменные:
```css

--primary-blue: #2196F3;
--warning-yellow: #FFC107;
--danger-red: #F44336;
```

Измените переменные → изменится весь сайт.

### Q: Как добавить новое поле в модель?
