# 🤝 Помощь Рядом

**Гиперлокальный P2P маркетплейс бытовых услуг с фокусом на доступность для пожилых людей**

---

## 📋 Описание проекта

**"Помощь Рядом"** — это веб-приложение, которое соединяет заказчиков и исполнителей услуг в одном районе. Основная особенность платформы — простота использования для пожилых людей: крупный шрифт, голосовой ввод и прямые звонки без необходимости освоения сложных чатов.

### Ключевые возможности:

✅ **Регистрация** — выбор роли (заказчик, исполнитель, оба)  
✅ **Создание заданий** — с голосовым вводом через Web Speech API  
✅ **Геолокация** — автоматическое определение района, фильтр заданий по расстоянию  
✅ **Оплата контактов** — исполнитель платит 50₽ через QR-код СБП, чтобы увидеть номер телефона заказчика  
✅ **Отзывы и рейтинги** — система оценок 1-5 звезд, комментарии  
✅ **Модерация** — лимиты на задания, антиспам, система жалоб, автоблокировка пользователей  
✅ **Адаптивный дизайн** — mobile-first, режим для пожилых (крупный шрифт, большие кнопки)

---

## 🛠 Технический стек

- **Backend**: Python 3.10+, Flask 3.0, Flask-SQLAlchemy, Flask-Login
- **Database**: SQLite (для MVP)
- **Frontend**: HTML5, CSS3 (custom CSS с переменными), Vanilla JavaScript (ES6+)
- **API**: Web Speech API (голосовой ввод), Geolocation API (геолокация)
- **Дополнительно**: qrcode (генерация QR-кодов), Werkzeug (хэширование паролей)

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/andreyburylov59/PomoshRyadom.git
cd PomoshRyadom
```

### 2. Создание виртуального окружения (опционально)

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

**Содержимое `requirements.txt`:**
```
Flask==3.0.0
Flask-SQLAlchemy==3.1.1
Flask-Login==0.6.3
qrcode==7.4.2
Pillow==10.1.0
Werkzeug==3.0.1
```

### 4. Инициализация базы данных

База данных создается автоматически при первом запуске приложения.

Если нужно пересоздать БД (например, после изменения моделей):

```bash
python3 recreate_db.py
```

### 5. Запуск приложения

```bash
python3 app.py
```

Приложение будет доступно по адресу: **http://127.0.0.1:5000**

## 📚 Основные функции

### 1. Аутентификация

- **Регистрация**: имя, телефон (+7...), пароль, роль (заказчик/исполнитель/оба), район
- **Вход**: телефон + пароль
- **Выход**: кнопка "Выход" в навигации
- **Профиль**: статистика, рейтинг, отзывы

### 2. Задания (CRUD)

- **Создание**: форма + голосовой ввод (Web Speech API)
- **Просмотр**: список с фильтрами (район, категория, срочность), сортировка по дате/цене
- **Редактирование**: только для автора, пока задание не завершено
- **Удаление**: только для автора
- **Завершение**: заказчик отмечает исполнителя и может оставить отзыв

### 3. Голосовой ввод

- Большая красная кнопка микрофона на странице создания задания
- Автоматическое распознавание:
  - Категория (11 категорий: уборка, доставка, сантехника и т.д.)
  - Цена (извлечение чисел из текста)
  - Адрес (ключевые слова: "по адресу", "улица")
  - Район (10 предустановленных районов)
  - Срочность (ключевые слова: "срочно", "быстро", "сегодня")
- Визуальная индикация: пульсация кнопки, вывод распознанного текста

### 4. Геолокация

- **Автоопределение района**: кнопка "📍 Определить район автоматически"
- **Фильтр по расстоянию**: показать задания в радиусе N км
- **Расчет расстояния**: формула Haversine для точного вычисления
- **10 районов**: Центральный, Северный, Южный, Западный, Восточный, Заречный, Промышленный, Нагорный, Октябрьский, Приморский

### 5. Оплата контактов

- По умолчанию номер телефона замаскирован: `+7 (902) ***-**-45`
- Исполнитель платит **50₽** через СБП (QR-код)
- После оплаты открывается полный номер и кнопка **"📞 Позвонить"** (`tel:`)
- Симуляция платежа: кнопка "Simulate Payment" для тестирования

### 6. Отзывы и рейтинги

- Оценка: 1-5 звезд (интерактивный выбор)
- Комментарий: текстовое поле
- Автоматический пересчет среднего рейтинга пользователя
- Отображение:
  - В профиле пользователя
  - На странице отзывов (с разбивкой по звездам)
  - Статистика: количество отзывов каждого типа

### 7. Модерация и безопасность

- **Лимиты**: максимум 5 активных заданий на пользователя
- **Антиспам**: запрет дублирования заданий с одинаковым названием в течение 1 часа
- **Система жалоб**: жалобы на задания и пользователей (4 причины: спам, мошенничество, неприемлемый контент, другое)
- **Автоблокировка**: пользователь блокируется после 3+ жалоб
- **Ограничения для заблокированных**: редирект на `/blocked`, доступен только выход

## 🧪 Тестирование

### Автоматические тесты

В проекте есть набор тестовых скриптов:

```bash
# Тест аутентификации
python3 test_auth.py

# Тест CRUD заданий
python3 test_tasks.py

python3 test_payment.py

# Тест отзывов
python3 test_reviews.py

# Тест модерации
python3 test_moderation.py
```

### Ручное тестирование

1. **Регистрация**:
   - Перейти на `/register`
   - Заполнить форму (телефон в формате `+7...`)
   - Проверить редирект на главную после регистрации

2. **Создание задания**:
   - Войти как заказчик
   - Перейти на `/task/create`
   - Попробовать голосовой ввод (кнопка микрофона)
   - Или заполнить форму вручную
   - Проверить создание задания

3. **Просмотр заданий**:
   - Перейти на `/tasks`
   - Применить фильтры (район, категория)
   - Попробовать фильтр по расстоянию
   - Кликнуть на задание для просмотра деталей

4. **Оплата контакта**:
   - Войти как исполнитель
   - Открыть любое задание
   - Нажать "Pay to get contact"
   - Проверить отображение QR-кода
   - Нажать "Simulate Payment"
   - Убедиться, что номер телефона разблокирован

5. **Отзывы**:
   - Войти как заказчик
   - Завершить задание (кнопка "✓ Завершить задание")
   - Выбрать исполнителя в модальном окне
   - Оставить отзыв (1-5 звезд + комментарий)
   - Проверить обновление рейтинга в профиле исполнителя

6. **Модерация**:
   - Создать 5 активных заданий
   - Попробовать создать 6-е (должна быть ошибка)
   - Пожаловаться на задание/пользователя (кнопка "🚨 Пожаловаться")
   - После 3 жалоб пользователь должен быть заблокирован

## 🔒 Безопасность

- **Хэширование паролей**: `werkzeug.security.generate_password_hash`
- **Защита роутов**: `@login_required` декоратор
- **Проверка прав**: владелец может редактировать/удалять только свои задания
- **Маскировка телефонов**: номера скрыты до оплаты
- **Система модерации**: автоматическая блокировка при 3+ жалобах
- **Антиспам**: ограничение на создание повторяющихся заданий

## 📊 База данных

### Модель `User`
- `id`, `name`, `phone` (unique), `password_hash`, `role`, `district`
- `latitude`, `longitude` (координаты)
- `rating` (default 5.0), `completed_tasks` (default 0)
- `is_verified` (default False), `is_blocked` (default False)
- `blocked_reason`, `blocked_at`, `created_at`

### Модель `Task`
- `id`, `user_id` (FK), `title`, `description`, `category`, `price`
- `address`, `district`, `latitude`, `longitude`
- `urgency` (срочно/планово/навыки), `status` (active/completed/cancelled)
- `phone_hidden` (маскированный), `executor_id` (FK)
- `created_at`, `completed_at`

### Модель `Payment`
- `id`, `task_id` (FK), `executor_id` (FK), `amount` (default 50)
- `qr_code_path`, `status` (pending/paid)
- `created_at`, `paid_at`

### Модель `Review`
- `id`, `task_id` (FK), `reviewer_id` (FK), `reviewee_id` (FK)
- `rating` (1-5), `comment`, `created_at`

### Модель `Report`
- `id`, `reporter_id` (FK), `reported_user_id` (FK), `reported_task_id` (FK)
- `reason` (spam/fraud/inappropriate/other), `description`
- `status` (pending/reviewed/resolved)
- `created_at`, `reviewed_at`

## 🌐 API эндпоинты

### Аутентификация
- `GET /register` — форма регистрации
- `POST /register` — создание пользователя
- `GET /login` — форма входа
- `POST /login` — вход в систему
- `GET /logout` — выход
- `GET /profile` — профиль пользователя

### Задания
- `GET /tasks` — список заданий (+ фильтры)
- `GET /task/create` — форма создания
- `POST /task/create` — создание задания
- `GET /task/<id>` — детали задания
- `GET /task/<id>/edit` — форма редактирования
- `POST /task/<id>/edit` — обновление задания
- `POST /task/<id>/delete` — удаление задания
- `POST /task/<id>/cancel` — отмена задания
- `GET /my-tasks` — мои задания

### Платежи
- `GET /task/<id>/pay` — страница оплаты контакта
- `POST /payment/<id>/simulate` — симуляция оплаты (тестирование)
- `GET /my-payments` — мои платежи

### Отзывы
- `POST /task/<id>/complete` — завершение задания
- `GET /task/<id>/review` — форма отзыва
- `POST /task/<id>/review` — отправка отзыва
- `GET /user/<id>/reviews` — отзывы пользователя
- `GET /my-reviews` — мои отзывы

### Модерация
- `GET /task/<id>/report` — форма жалобы на задание
- `POST /task/<id>/report` — отправка жалобы
- `GET /user/<id>/report` — форма жалобы на пользователя
- `POST /user/<id>/report` — отправка жалобы
- `GET /my-reports` — мои жалобы
- `GET /blocked` — страница для заблокированных пользователей
